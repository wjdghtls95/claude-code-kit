# lookup

[English](README.md) | [한국어](README.ko.md)

작업하면서 무언가를 제대로 찾아보기 위한 플러그인입니다. 자주 나오는 질문은 두 종류입니다.

- **코드** — "이 라이브러리로 X 어떻게 해", "이 에러 뭐야", "예제 보여줘". 답이 **내 프로젝트에 실제로 설치된 버전**에 맞아야 합니다. 웹 예제가 가장 자주 틀리는 지점입니다.
- **정보** — "아직 지원돼?", "뭐가 바뀌었어", "A와 B 중 뭐가 나아", "최신은 뭐야". 답이 **1차 자료**에서 나오고 **지금 기준**이어야 합니다.

이 플러그인이 하는 일입니다.

- **find 스킬**(`/lookup:find`)이 순서를 정합니다. 먼저 프로젝트 안을 봅니다(이미 쓰는 코드, 설치된 버전, 설치된 소스와 타입). 그다음 그 버전의 공식 문서, 변경 기록, 라이브러리 저장소, 이슈를 보고, 블로그는 마지막에 봅니다. 정보 검색은 1차 자료를 우선하고, 답의 근거가 되는 페이지는 직접 열어 보고, 날짜를 확인하고, 중요한 내용은 서로 다른 출처 두 곳으로 확인합니다.
- **작은 스크립트**가 라이브러리의 **설치된 버전과 로컬 소스 폴더**를 찾습니다. npm(package.json, 잠금 파일, pnpm 작업 공간을 포함한 node_modules), 파이썬(pyproject, requirements, uv.lock, poetry.lock, 가상환경 site-packages), Go(루트 go.mod의 버전만)를 지원합니다. npm과 파이썬은 설치된 패키지 안에 든 변경 기록과 README, 저장소와 홈페이지 링크, 그리고 파이썬 패키지가 적어 둔 변경 기록과 문서 링크도 함께 알려 줘서, 스킬이 정확히 그 버전의 변경 내역을 읽고 맞는 저장소를 엽니다.
- **알림 훅**은 메시지가 분명히 찾아보는 요청일 때 Claude에게 기억으로 답하지 말고 find 스킬을 쓰라고 알립니다. 분명한 요청은 "검색해줘", "찾아봐", "알아봐", "search for", "look up" 같은 직접 요청, "코드 알려줘", "예제", "how do I" 같은 코드 요청, 붙여 넣은 에러 메시지, 그리고 라이브러리 같은 도구 이름이나 버전이 함께 있는 메시지의 "최신", "지원돼?", "차이", "latest"입니다. "어떻게 생각해", "좋을까" 같은 의견이나 계획 질문에는, 검색이나 코드를 함께 요청하지 않는 한 붙지 않습니다. 실제 메시지 약 1,200개에서 2% 미만에만 붙었습니다. 한 줄 안내만 붙이고, 막지 않고, 메시지를 되풀이하지 않습니다. 이 훅이 없으면 스킬을 설치해도 Claude가 기억으로 답하는 경우가 많습니다.

모든 답은 **Sources**(링크나 파일과 줄, 버전이나 날짜)와 **Not confirmed**(확인하지 못한 것)로 끝납니다.

## 설치

```
/plugin marketplace add wjdghtls95/claude-code-kit
/plugin install lookup@claude-code-kit
```

필요한 것: 스크립트와 알림을 위한 `python3`(표준 라이브러리만 사용). GitHub CLI `gh`가 있으면 저장소와 이슈 검색에 씁니다.

## 사용

그냥 물어보면 됩니다. 확실히 쓰고 싶으면 직접 부르세요.

```
/lookup:find bullmq에서 반복 작업 삭제하는 법
```

스크립트만 따로 실행해도 됩니다.

```
python3 scripts/project_context.py bullmq --root .
```

## 알림 끄기

환경 변수 `LOOKUP=off`(`0`, `false`, `no`, `disable`, `disabled`도 가능)를 쓰거나 `/plugin disable lookup`로 끕니다.

## 한계

- 알림은 문구로 판단해서, 질문을 놓치거나(그때는 `/lookup:find`로 부르면 됩니다) 검색이 필요 없는 질문에 붙을 수 있습니다. 안내일 뿐입니다.
- 버전 스크립트는 매니페스트와 잠금 파일을 읽기만 합니다. 패키지 관리자를 실행하지 않습니다.
- 검색 품질은 세션에서 쓸 수 있는 웹 검색과 가져오기 도구에 좌우됩니다.
